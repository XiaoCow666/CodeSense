## 方案与必要性

- 本轮主方案是核验学生、教师与知识图谱/学生向量库实际流程。学生需要从作业和个人反馈继续学习；教师需要维护作业知识点并查看受限班级汇总；AI 辅导需要按学生与作业范围读取可解释来源。
- 成功条件：教师编辑作业知识点后，学生图谱、教师面板、作业辅导知识检索和学生向量查询遵守当前来源及权限；学生撤回来源后检索不再返回该来源；窄屏和时间显示候选通过受影响角色路径核验。
- 已发布 v2.0.0 已含图谱和向量纵向流程。本轮没有发现可复现的新图谱或向量故障。为了满足交付数量而改写健康代码会增加维护成本，本轮没有新增猜测性产品行为。
- 研究来源：2026-09-29 查阅 [OpenAI Vector Stores API Reference](https://developers.openai.com/api/reference/resources/vector_stores)。官方接口说明检索支持属性过滤、文件可删除。针对 CodeSense 的设计约束是先按学生、作业、来源状态缩小候选，再计算相似度；撤回后的来源不得继续命中。CodeSense 使用本地 SQL 与稀疏向量实现，没有采用托管 Vector Stores API。
