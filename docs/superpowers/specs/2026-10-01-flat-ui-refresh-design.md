# CodeSense 纯色界面改版设计

日期：2026-10-01
Figma 草图：https://www.figma.com/design/NKLZ19BDlAbwveKe6tHV6k

## 目标

将 CodeSense 的产品界面统一为简洁、舒适、灵活的纯色视觉语言，重点解决代码提交页 AI 编程助手在窄屏上知识卡过高、回复正文过窄、引用内容挤压的问题。保留现有功能、文案语义和服务端渲染方式。

## 范围

- 产品自有 CSS 和 Jinja 模板中的蓝紫色系、渐变背景及相关悬停状态；不修改 Bootstrap、Monaco 等第三方资源。
- 共用导航、按钮、卡片、表单、提示、状态标签与 AI 消息的颜色、边框、间距和焦点状态。
- 代码提交页的桌面与窄屏助手布局，以及知识证据面板的紧凑展示。
- 已存在渐变的登录、注册、个人资料、学生与教师首页、班级、帮助、反馈、分析等页面。按同一视觉规则调整，避免只修截图中的一页。

当前 `origin/main` 中自有样式约有 57 处渐变声明，分布于 27 个文件。这是基线清单，实施时重新扫描并逐一处理。

## 视觉基础

| 用途 | 颜色 |
| --- | --- |
| 页面背景 | `#F5F7F8` |
| 内容表面 | `#FFFFFF` |
| 主文字 | `#23343D` |
| 次文字 | `#64757D` |
| 分隔线 | `#DDE5E6` |
| 主要操作 | `#237B75` |
| 强调浅底 | `#EAF4F2` |
| 输入浅底 | `#F0F3F3` |

保留语义性成功、警告、错误颜色，但降低饱和度并保证对比度。主要操作使用青绿色纯色；信息层级主要通过字号、留白、细边框和文字重量表达。中文正文优先使用系统可用的无衬线字族，代码继续使用等宽字族。按钮和卡片采用适度圆角，不使用大面积阴影或装饰性渐变。交互状态以纯色、边框和清晰的键盘焦点体现。

## 页面与组件

1. 在共享样式中定义语义化视觉变量，并让通用控件引用变量。页面局部样式可以扩展，但不再各自发明主色和渐变。
2. 保持 Flask/Jinja、Bootstrap 和现有 JavaScript 架构。复用现有模板宏与 CSS 组件；不为视觉改版引入 React 运行时或重写路由。
3. 代码提交页桌面布局保留编辑器与助手并列，助手提供足够阅读宽度；较窄视口改为顺序布局，避免侧栏被压到无法阅读。
4. AI 助手顶部使用简洁标题栏。知识焦点默认显示短摘要和证据数量，证据列表可展开；回复正文占可用宽度，长词、代码、表格、引用均不得造成横向溢出。输入区在助手底部保持可见。
5. 知识证据在其他页面仍维持完整展示；紧凑模式只改变代码提交页的呈现，不删减证据数据或来源。

## 适配与可访问性

- 在 1440、768、390 和约 320 CSS 像素宽度检查关键页面；内容可换行，操作按钮有足够点击面积。
- 保持焦点可见、文字与控件对比度充足；尊重减少动画偏好。
- 证据展开状态有语义化控件和可访问名称；现有快捷提问、发送、清空、流式消息和证据重试继续可用。

## 验收

- 产品自有 CSS/模板不再出现 `linear-gradient(` 或 `radial-gradient(` 声明；第三方静态资源除外。
- AI 助手在窄屏不出现截图中的三列挤压和横向滚动，知识列表展开后可完整阅读。
- 全站共用控件和至少登录、学生首页、教师首页、代码提交四个代表性页面视觉一致。
- 现有相关行为测试通过；浏览器检查桌面与窄屏，确认布局和交互状态。

## 发布

先在独立工作区完成代码与验证，再将变更并入主分支。线上部署需要单独验证静态资源缓存和真实页面显示；Figma 是设计参照，不替代浏览器验收。
