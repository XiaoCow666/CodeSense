# CodeSense v2.1.0：作业知识资料走进学习路径

教师现在可以在作业编辑页，为已关联的知识点发布学习资料，并在需要时更新或撤回。每次更新会保留版本记录，方便核对资料如何变化。

学生可以从首页知识路径进入对应资料，在作业页阅读后继续练习。AI 辅导会引用当前资料并显示来源版本，便于回看解释依据。

资料撤回或关联知识点移除后，学生页面、知识路径和 AI 引用会同步停止展示。个人学习记忆仅在学生本人有权访问的范围内检索；所有来源均撤回时会显示空数据状态。
