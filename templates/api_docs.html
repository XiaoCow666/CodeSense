CodeSense 酷森思API接口说明

API概述

CodeSense 酷森思提供了一组RESTful API，允许开发者通过编程方式访问系统功能。所有API都返回JSON格式的数据，使用标准的HTTP状态码表示请求状态。

认证

大多数API需要用户身份验证才能访问。认证通过基于会话的Cookie进行，这意味着您需要先通过网页登录系统，然后才能使用API。

响应格式

所有API响应都有以下统一的JSON格式：

{
  "success": true,          // 操作是否成功
  "message": "获取成功",    // 操作消息
  "data": {                 // 返回的数据
    // 具体数据
  }
}

作业相关API

获取所有作业列表

{

  "message": "获取作业列表成功",
  "data": {

      // ... 更多作业

GET /api/assignments/{assignment_id}

获取指定作业的详细信息

参数
参数名 参数位置 类型 描述
assignment_id必填 URL 整数 作业ID
响应示例
{
  "success": true,
  "message": "获取作业详情成功",
  "data": {
    "assignment": {
      "id": 1,
      "title": "冒泡排序算法",
      "description": "实现一个冒泡排序算法，对整数数组进行排序。",
      "average_score": 70.0,
      "count": 25,
      "total_score": 1750.0,
      "created_time": "2023-05-10T14:30:00"
    }
  }
}

使用示例

JavaScript示例

// 获取所有作业
async function getAssignments() {
  try {
    const response = await fetch('/api/assignments');
    const result = await response.json();
    
    if (result.success) {
      console.log('作业列表:', result.data.assignments);
      return result.data.assignments;
    } else {
      console.error('获取作业失败:', result.message);
      return [];
    }
  } catch (error) {
    console.error('API请求错误:', error);
    return [];
  }
}

Python示例

import requests

# 获取学生提交记录
def get_student_submissions(student_id):
    try:
        # 注意：需要包含会话Cookie进行身份验证
        response = requests.get(f'http://example.com/api/submissions/{student_id}')
        result = response.json()
        
        if result['success']:
            print(f"学生 {student_id} 的提交记录:", result['data']['submissions'])
            return result['data']['submissions']
        else:
            print("获取提交记录失败:", result['message'])
            return []
    except Exception as e:
        print("API请求错误:", str(e))
        return []
